# Статус · Политическая хронология

Интерактивный архив программы Екатерины Шульман и Максима Курникова. В снимке 216 уникальных выпусков, 1 806 сюжетов и 34 действия, сверенные по документам. Стенограммы опубликованы с 23 марта 2022 по 11 ноября 2026 года. [Первоисточник на Teletype](https://teletype.in/@eschulmann).

## Открыть портал

Клонируйте или скачайте репозиторий и откройте `Портал/index.html` в браузере. График, фильтры, дерево и саммари работают локально. Ссылки ведут в оригиналы стенограмм и официальные документы.

- `Портал/` — интерфейс и данные снимка.
- `Стенограммы/` — 219 пар файлов по годам. У стенограммы и её саммари общий префикс имени.
- [Как открыть и читать архив](Как%20открыть.md) — охват, методика и основные результаты.
- `scripts/` — скачивание, подготовка, тематическая разметка и сборка. Сверенные карточки хранятся в `scripts/verified.json`.

## Собрать из исходных публикаций

Скрипты проверены с Python 3.13. Запускайте из корня репозитория. Загрузка обращается к открытому каталогу Teletype. При изменении каталога состав нового снимка может отличаться.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python scripts/download.py
.venv/bin/python scripts/prepare.py
.venv/bin/python scripts/analyze.py
.venv/bin/python scripts/build.py
```

Промежуточные данные остаются в `scripts/.cache/`. Сборка обновляет папку стенограмм, саммари и данные портала. Сверенные даты и роли обновляются через `scripts/verified.json`.
